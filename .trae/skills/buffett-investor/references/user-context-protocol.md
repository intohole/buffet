# User Context Protocol - 用户上下文加载与更新协议

**技能不依赖任何项目特定数据**。用户上下文是可选的，存放于工作区（非技能目录）。缺失上下文时优雅降级，仅输出通用分析。

## 路径规则

用户数据位于工作区根目录下的 `.investor-context/` 目录（相对工作区根，非技能目录）：

| 文件 | 用途 |
|------|------|
| `${WORKSPACE_DIR}/.investor-context/user-portfolio.md` | 当前持仓 |
| `${WORKSPACE_DIR}/.investor-context/user-profile.md` | 投资风格画像 |
| `${WORKSPACE_DIR}/.investor-context/trade-history.md` | 操作日志 |

**跨机器兼容**：禁止使用绝对路径，所有路径相对于工作区根目录。

## 加载协议（可选，优雅降级）

### Step 1: 检查上下文目录

使用 LS 工具检查工作区根目录下 `.investor-context/` 目录是否存在。

- **存在** → 执行 Step 2-4 加载用户上下文
- **不存在** → 跳过用户上下文加载，仅输出通用分析，不输出个性化建议

### Step 2: 读取用户持仓（若文件存在）

使用 Read 工具读取 `${WORKSPACE_DIR}/.investor-context/user-portfolio.md`：
- 当前持仓列表（股票/代码/持股数/成本价/止损位/目标价）
- 持仓统计（总市值/总盈亏/仓位分布/行业集中度）
- 未卖出股票监控列表
- 已清仓记录

### Step 3: 读取用户画像（若文件存在）

使用 Read 工具读取 `${WORKSPACE_DIR}/.investor-context/user-profile.md`：
- 投资风格（价值/成长/集中/分散/左侧/右侧）
- 能力圈评估（各行业熟悉度）
- 行为特征和个性化建议
- 历史分析偏好（各模式使用频率）

### Step 4: 读取操作历史（若文件存在）

使用 Read 工具读取 `${WORKSPACE_DIR}/.investor-context/trade-history.md`：
- 完整操作日志（买入/卖出记录）
- 操作统计（买入/卖出次数/金额/胜率）
- 操作行为分析（止损执行率/操作频率）

### Step 5: 上下文融合（若上下文存在）

将用户上下文融入本次分析：
- 持仓诊断模式：直接使用持仓数据，无需用户重复输入
- 选股/热点模式：推荐标的需考虑与现有持仓的相关性和分散性
- 买卖时机模式：判断是否与用户现有持仓冲突
- 所有模式：检查推荐标的是否在用户能力圈内
- 所有模式：根据用户风险偏好调整建议力度
- 所有模式：若止损执行率低则强调止损纪律

**优雅降级**：若上下文不存在，跳过以上融合，输出通用分析。

## 更新协议（可选，仅当上下文目录存在时）

**仅当工作区存在 `.investor-context/` 目录时执行更新**。若不存在，跳过更新，在报告末尾提醒用户可创建该目录以启用个性化能力。

### 更新用户持仓

- 用户明确说"已买入"/"已建仓"/"已加仓"/"买了" → 更新 `user-portfolio.md` 当前持仓
- 用户明确说"已卖出"/"已减仓"/"已清仓"/"卖了" → 更新 `user-portfolio.md`，添加到已清仓记录
- 用户未确认操作 → 不更新持仓，在报告中提醒用户确认

### 更新操作历史

- 用户确认买卖操作 → 添加操作日志
- 更新操作统计（次数/金额/胜率）
- 更新操作行为分析（止损执行率等）

### 更新用户画像

- 更新"最近活跃"为当天日期，"累计分析次数"+1
- 更新"历史分析偏好"
- 若发现新行为特征 → 更新"行为特征"
- 若用户能力圈扩展 → 更新"能力圈评估"

## 首次运行引导

若工作区无 `.investor-context/` 目录，首次运行时在报告末尾输出引导：

```
💡 启用个性化投资分析能力：
创建工作区目录 .investor-context/，添加以下文件（可选）：
- user-portfolio.md：当前持仓（格式：股票/代码/持股数/成本价/止损位/目标价）
- user-profile.md：投资风格画像
- trade-history.md：操作日志

启用后，分析将考虑您的持仓分散性、风险偏好和能力圈。
```

## 与技能的解耦关系

本协议是**可选的增强能力**，技能核心功能（5+1层框架+研究员7步闭环+热点漏斗+硬约束）不依赖任何用户上下文。即使用户未启用上下文，技能仍可输出完整的通用投资分析。
