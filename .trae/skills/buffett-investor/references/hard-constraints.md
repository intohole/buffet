# Hard Constraints - 通用高置信度硬约束

经多源搜索验证的通用决策规则，违反即触发预警。这些规则不依赖任何项目特定经验文件，是A股分析的通用铁律。

|------|---------|---------|---------|
| 业绩虚胖淘汰 | 扣非净利润/归母净利润<50% | 选股阶段直接淘汰；50-80%降级处理 | 中国证券报/雪球（华天科技/中科蓝讯/南京熊猫多案例验证） |

### 高股息/深度破净标的价值陷阱识别（大秦铁路实战+多源搜索验证）

**核心认知**: 深度破净(PB<0.6)+高股息(>5%)≠安全边际。A股高股息标的中80%的"高息"是股价暴跌后的被动虚高，须通过以下硬约束排除价值陷阱。

| 规则 | 触发条件 | 触发动作 | 验证来源 |
|------|---------|---------|---------|
| 价值陷阱三重验证 | PB<0.6深度破净标的: (1)净利润连续2季度下滑 (2)股东户数半年增幅>50% (3)主力连续20日净流出 | 3项中2项恶化=价值陷阱，一票否决 | 大秦铁路实战(6.74→4.57跌32%)+Investing.com/Piotroski F-Score多源验证 |
| 散户集中营回避 | 股东户数半年翻倍+机构持股<10% | 选股阶段直接淘汰，散户主导标的无人抬轿 | 大秦铁路实战(16.92万→32.75万户)+银行股71.6%散户持筹8成亏损统计 |
| 股息陷阱识别 | 净利润连续2季度下滑但股息率>5% | 判定"被动高息"假象，禁止作为买入理由 | 大秦铁路实战(2025净利-34.7%但股息5%+)+Investormint"falling earnings+high yield=trap" |
| 分红率可持续性 | 分红率>90% | 预警"吃老本"风险，需验证业绩趋势；健康区间30%-70% | 数据宝/高股息陷阱研究多源验证(>90%属竭泽而渔) |
| 分红现金流验证 | 经营现金流净额<净利润 或 现金流/分红总额<1.5倍 | 分红真实性存疑，降级处理 | 高股息陷阱揭秘4维框架 |
| 分红连续性 | 现金分红连续<5年 或 分红比例波动>10% | 分红"肌肉记忆"未验证，降级处理 | 18家千亿龙头筛选框架(连续5年分红穿越周期) |
| 深度破净止损加严 | PB<0.6标的跌破止损位 | 严禁延迟执行，深度破净标的反弹弱、流动性差 | 大秦铁路实战(延迟5日扩大亏损2.9%+) |

### 选股财务质量硬约束（Piotroski F-Score框架+8层漏斗实战验证）

**核心认知**: 斯坦福教授Piotroski 2000年发布9项财务健康评分体系，20年回测高分股(7-9分)跑赢低分股(0-3分)23%/年。开普敦大学研究证实F-Score在A股市场同样有效：高F-Score组合显著跑赢低F-Score组合，尤其在低BM股中每月超额收益1.28%（来源：UCT学术研究+SJEMR中国A股实证）。以下硬约束将F-Score本土化适配A股。

| 规则 | 阈值 | 触发动作 | 验证来源 |
|------|------|---------|---------|
| 净现比验证 | 经营现金流/净利润 < 0.8 | 剔除，账面利润无真实现金支撑 | 8层漏斗选股法(2026年A股实战验证) |
| 应收账款预警 | 应收账款占营收比连续2年上升 | 剔除，暴雷前最常见红旗信号 | 东方财富+新浪财经多源验证 |
| 现金流质量 | 经营现金流净额 < 净利润 | 降级处理，利润含金量不足 | Piotroski F-Score Test 4 |
| 财务改善趋势 | ROA较上年下降 或 资产负债率较上年上升 | 降级处理，基本面在恶化 | Piotroski F-Score Test 3/5 |
| 股本稀释预警 | 近一年新发股份 | 警惕，公司无法靠自身运营融资 | Piotroski F-Score Test 7 |
| 毛利率稳定性 | 毛利率较上年下降>3个百分点 | 降级处理，竞争格局恶化 | Piotroski F-Score Test 8 |
| 资产周转率 | 资产周转率较上年下降 | 降级处理，运营效率下滑 | Piotroski F-Score Test 9 |
| 综合F-Score | 9项测试中得分<5分 | 剔除；5-7分谨慎评估；8-9分通过 | Piotroski 20年回测验证(7-9分跑赢23%/年) |

## 四、数据验证类硬约束

WebSearch数据常混入往年同日数据，导致价格/指数失真。

| 校验项 | 规则 | 不通过处理 |
|--------|------|-----------|
| 涨跌停校验 | 主板单日涨跌幅≤10%，创业板/科创板≤20% | 超限标记"数据异常"，用前日收盘价±10%估算 |
| 年份校验 | 搜索结果年份必须与当前年份一致 | 非当前年份标记"历史数据"，不用于决策 |
| 指数合理性 | 上证2500-6000，沪深300 3000-7000 | 超范围标记"数据异常" |
| 价格一致性 | 同一标的不同来源偏差<2% | 偏差>2%取中位数，标注"数据存疑" |
| 成交额合理性 | 沪深两市日成交额5000亿-5万亿 | 超范围标记"数据异常" |

**硬约束**：未通过校验的数据禁止用于买入/卖出决策。

## 六、政策传导类硬约束（历史5轮验证+2026实战）

**核心认知**: A股是典型政策驱动型市场，政策传导链固定为"政策底→资金底→市场底→业绩底"，历史5轮（2005/2008/2012/2018/2022）验证政策底→市场底平均滞后1.5-3个月。

| 规则 | 触发条件 | 触发动作 | 验证来源 |
|------|---------|---------|---------|
| 政策周期定位 | 所有分析前必须判定当前政策周期阶段 | 未定位禁止输出操作建议 | 华西证券/粤开策略5轮历史复盘 |
| 政策压制禁入 | 政策关键词含"调控/压降/规范/限制/整顿" | 禁止推荐相关板块，即使技术面良好 | 东方财富政策分析体系 |
| 政策底确认 | 国家队增持>500亿+降准降息+证监会稳市 | 禁止恐慌卖出，提示逆向布局机会 | 2026年7月中国国新+诚通600亿增持实战 |
| 市场底未确认 | 政策底已确认但未满足:地量+不破前低+放量阳线 | 禁止满仓，保持2-3成底仓试错 | 历史规律滞后1.5-3个月 |
| 政策时效性识别 | 长期战略(3-5年)vs年度基调vs短期货币 | 区分配置:长期战略可重仓/短期已兑现不追 | 五年规划+中央经济工作会议跟踪体系 |
| 政策传导验证 | 政策落地→订单增加→业绩兑现链条 | 缺任一环节=伪赛道，降级处理 | 东方财富"政策→行业→个股"传导框架 |
| 增持主体识别 | 央企/国家队增持 vs 散户/游资跟风 | 仅央企/国家队增持=政策底信号;游资独买=题材炒作 | 2026年7月8家央企集中增持120亿+实战 |
| 政策日历跟踪 | 月度PMI/社融+季度央行报告+年度经济工作会议 | 必须在分析中引用最新政策数据 | 东方财富政策监控体系 |
