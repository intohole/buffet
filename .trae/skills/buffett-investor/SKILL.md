## 5+1层分析框架

```
Layer 0: 前瞻与预判 (Forward-Looking) → 产业趋势/政策/技术/供需预判
Layer 1: 风险与纪律 (All Masters)     → 资金保全与情绪控制
Layer 2: 价值与护城河 (Buffett)       → 商业质量与内在价值 + 护城河耐久性
Layer 3: 成长分类 (Lynch)             → 股票类型识别 + 渗透率/替代率定位
Layer 4: 趋势与时机 (Livermore)       → 入场/出场时机 + 领先信号确认
Layer 5: 宏观与反射性 (Soros)         → 市场环境与泡沫检测 + 范式转换预判
```

### Step 0: 市场周期识别（最高优先级，决定策略基调）

**为什么必须先做**: 不同市场周期下，同一策略效果天壤之别。牛市用防御策略=踏空，熊市用进攻策略=亏损。此步骤决定后续所有分析的策略基调。

执行3项并行WebSearch：
```
1. "上证指数 沪深300 位置 均线 {今日日期}"
2. "A股 成交额 融资余额 北向资金 {今日日期}"
3. "A股 PE分位 估值水平 证券化率 {今日日期}"
```

**4阶段判定规则**（必须全部满足3项以上才能判定该阶段）：

| 阶段 | 涨幅条件 | 均线条件 | 成交条件 | 估值条件 | 策略基调 |
|------|---------|---------|---------|---------|---------|
| **底部蓄势** | 从低点<20% | 年线下方，短均缠绕 | 地量，较前期缩30%+ | PE<历史30%分位 | 逆向分批布局 |
| **修复上行** | 从低点20-50% | 站稳年线，短均向上发散 | 放量，较前期增30%+ | PE历史30-50%分位 | **积极进攻**，仓位>60% |
| **景气主升** | 从低点50-80% | 多头排列，斜率陡峭 | 天量，持续高位 | PE历史50-70%分位 | **进攻+警惕**，紧贴主线 |
| **高位分化** | 从低点>80% | 短均走平或下压 | 缩量或天量后萎缩 | PE>历史70%分位 | 防御为主，逐步减仓 |

**关键输出**: `当前阶段=XXX` + `策略基调=进攻/均衡/防御`，此结论贯穿后续所有分析步骤。

**硬约束**:
- 修复上行/景气主升阶段，**禁止**将"等回调"作为默认建议，必须给出趋势确认买入方案
- 高位分化阶段，**禁止**推荐追高，所有建议必须附带减仓条件
- 底部蓄势阶段，**禁止**恐慌卖出，应提示逆向布局机会

### Step 0.1: 数据验证（所有WebSearch数据必须通过）

**为什么必须做**: WebSearch结果常混入往年同日数据（如2025年数据混入2026年搜索结果），导致价格/指数严重失真，直接造成错误决策。

**A股硬性校验规则**:

| 校验项 | 规则 | 不通过处理 |
|--------|------|-----------|
| 涨跌停校验 | 主板单日涨跌幅≤10%，创业板/科创板≤20% | 超限数据标记为"数据异常"，用前日收盘价±10%估算 |
| 年份校验 | 搜索结果中的年份必须与当前年份一致 | 非当前年份数据标记为"历史数据"，不用于决策 |
| 指数合理性 | 上证指数范围2500-6000，沪深300范围3000-7000 | 超范围数据标记为"数据异常" |
| 价格一致性 | 同一标的在不同搜索结果中价格偏差<2% | 偏差>2%时取多个来源的中位数，标注"数据存疑" |
| 成交额合理性 | 沪深两市日成交额范围5000亿-5万亿 | 超范围数据标记为"数据异常" |

**数据异常处理流程**:
1. 标注"⚠️数据异常" + 具体原因
2. 尝试用其他搜索关键词重新获取
3. 若仍无法验证，在报告中明确标注"该数据未经验证，仅供参考"
4. **禁止**用异常数据作为买入/卖出的唯一依据

### Step 0.2: 经验检索（含踏空成本维度）

1. 用 Grep 在 `investment-experience/` 目录搜索相关经验（关键词匹配）
2. 若匹配则读取（最多3条），提取历史判断的正确/错误经验
3. **踏空成本检查**: 搜索"等回调"/"观望"/"回避"类经验，评估是否有踏空记录
4. **踏空成本量化公式**: 踏空成本 = (期间指数/板块涨幅) × 计划仓位 × 持仓周期。若踏空成本>潜在回调损失，则"等回调"策略净负收益
5. 若无匹配则跳过

### Step 0.5: 前瞻信号检索

1. 用 Grep 在 `investment-experience/forward-signals.md` 搜索当前分析领域的前瞻信号
2. 若有匹配的前瞻信号，纳入本次分析的领先指标参考
3. 前瞻信号框架: [forward-looking.md](forward-looking.md)

### Step 1: Layer 1 风险检查

- 能力圈: 能否用3句话解释该业务？
- 情绪: 是否出于恐惧/贪婪/希望？若是则警告
- 资金规则: 不用杠杆、不向下摊平、单股≤20%、现金≥10%、预设止损7-8%
- 回撤检查: 当前账户回撤是否触及警戒线？详见 [risk-control.md](risk-control.md)
- **周期适配**: 当前策略基调是否与Step 0判定的市场周期一致？不一致则警告

## 热点→选股漏斗（核心工作流）

### Phase 1: 热点信息采集

**必须执行4批次并行WebSearch**（每批≥3个搜索，总计≥12次）。

**日期规则**: 搜索关键词中的日期必须使用系统当前日期。季度根据月份推算（1-3月=Q1，4-6月=Q2，7-9月=Q3，10-12月=Q4）。

```
批次1-市场面:
  "A股今日热点板块 涨停 {今日日期}"
  "主力资金流向 机构加仓 {今日日期}"
  "北向资金 今日流入 板块 {今日日期}"
  "两市成交额 量能变化 {今日日期}"

批次2-A股特色数据（必须执行）:
  "A股 涨停板 连板梯队 {今日日期}"
  "龙虎榜 机构席位 游资席位 {今日日期}"
  "涨停数量 跌停数量 封板率 {今日日期}"
  "换手率排名 量比排名 {今日日期}"

批次3-政策面+业绩面:
  "政策利好 产业政策 最新 {今日日期}"
  "业绩超预期 {当前季度}报 {当前年份}"
  "行业景气度 景气上行 {当前年份}"
  "净利润增长 业绩爆发 {当前年份}"

批次4-事件面:
  "突发新闻 财经 今日 {今日日期}"
  "全球市场 美股 美联储 影响"
  "大宗商品 原油 铜 黄金 价格"
```

**对每个候选热点，执行5项纵深搜索**:
```
1. "[热点名称] 龙头股 核心标的 {当前年份}"
2. "[热点名称] 订单 业绩 验证 {当前季度}报"
3. "[热点名称] 产业链 上中下游 受益股"
4. "[热点名称] 风险 争议 利空"
5. "[热点名称] 券商研报 目标价 评级 {当前年份}"
```

**反馈闭环**: 若纵深搜索发现业绩无法验证或存在重大风险，必须降低该热点评分或直接淘汰。

### Phase 2: 热点质量评估（4维12分制）

| 维度 | 高质量(3分) | 中等(2分) | 低质量(1分) |
|------|-------------|-----------|-------------|
| 政策支持 | 国家级政策，多年周期 | 部委/地方政策 | 无政策支持 |
| 资金流向 | 主力净流入持续3天+，金额>50亿 | 1-2天流入，金额<50亿 | 无明确流入或净流出 |
| 业绩验证 | 真实业绩增长确认 | 预期增长，尚未兑现 | 无业绩支撑，纯概念 |
| 板块广度 | 多股涨停(>5只)，梯队完整 | 1-2只龙头涨停 | 仅单只上涨 |

- ≥10分 = ✅可持续主线 → 根据周期基调配置仓位（修复上行15-20%，景气主升12-18%，高位分化8-12%，底部蓄势5-10%）
- 6-9分 = ⚠️次级题材 → 适度参与，轻仓（修复上行10-15%，景气主升8-12%，高位分化5-8%，底部蓄势3-5%）
- <6分 = ❌一日游 → 回避

### Phase 3: 垂直领域确认

| 检查项 | 通过标准 | 未通过处理 |
|--------|----------|-----------|
| 有中军股(大盘龙头稳健上涨) | 机构信心确认 | 降低仓位预期 |
| 板块指数突破20日均线 | 趋势确认 | 等待突破 |
| 资金连续3天净流入 | 资金确认 | 继续观察 |
| 有政策催化 | 政策确认 | 降低持续性预期 |

- 4项全通过=高确定性→根据周期基调配置（修复上行15-20%，景气主升12-18%，高位分化8-12%，底部蓄势5-10%） | 3项=中等→8-12% | ≤2项=仅观察

### Phase 4: 上市公司筛选

**第一层: 龙头/中军/补涨分类**

| 分类 | 特征 | 仓位上限 |
|------|------|---------|
| 龙头 | 板块内首个涨停/连板数最高/封板坚决/基本面有催化 | ≤15% |
| 中军 | 大盘龙头/ROE>15%/稳健上涨/代表机构信心 | ≤20% |
| 补涨 | 同板块未涨/基本面不错但滞后 | ≤5% |

**A股龙头战法增强检查**（每个候选龙头必须执行）:

| 指标 | 通过标准 |
|------|---------|
| 龙虎榜 | 机构净买入 或 机构+游资同买 |
| 连板质量 | 早盘封板+封单>5%+换手5-15% |
| 筹码集中度 | 连续2季度股东户数减少>10% |
| 量比 | 当日量比2.5-5(明显放量) |
| 题材收入占比 | >5%(非蹭热点) |

**第二层: 5层框架快速筛选**

| 层级 | 通过标准 | 未通过处理 |
|------|----------|-----------|
| Layer 0 | 产业趋势可预判，非纯概念 | 淘汰 |
| Layer 1 | 能解释业务，非FOMO | 淘汰 |
| Layer 2 | 护城河≥5分，财务≥5/7 | 淘汰 |
| Layer 3 | 正确分类+PEG合理+渗透率定位 | 调整策略 |
| Layer 4 | 非派发期+领先信号确认 | **周期适配**: 修复上行/景气主升→趋势确认可入场；高位分化→等待回调 |
| Layer 5 | 非系统性风险+范式未转换 | 降低仓位 |

**第三层: 割裂度筛选**

1. 板块背离: 板块回调时个股不跌 → 强主力
2. 大盘背离: 大盘创新低个股不跟 → 独立强势
3. 量价背离: 价涨量增价跌量缩 → 健康吸筹

3项全通过=强割裂 | 2项=中等 | ≤1项=弱(谨慎)

```
3. "[股票名] 管理层 增持 分红 回购"
4. "[股票名] 券商研报 目标价 评级 {当前年份}"
5. "[股票名] 风险 利空 争议"
6. "[股票名] 技术分析 均线 MACD 趋势"
7. "[行业] 行业趋势 格局 增速 {当前年份}"
```

**A股红旗检查**（每个标的必须执行，严禁跳过）:

14项红旗检查清单详见 [deep-analysis.md](deep-analysis.md) 的「A股红旗检查清单」章节。核心淘汰标准：

- 龙虎榜机构卖出+游资买入→出货信号

### Step 7: 经验沉淀

分析完成后，**必须**将经验沉淀到项目根目录 `investment-experience/` 目录。详细协议：[review-loop.md](review-loop.md)。

**核心规则**：
1. 读取 `investment-experience/experience-index.md` 获取现有经验索引
2. 若有新经验，追加并更新对应分类文件；若无则跳过
3. 经验锤炼：本次观察与已有经验一致→提升置信度；矛盾→降低置信度并标注"待验证"
4. 置信度=高→可直接写入决策规则；置信度=低→仅参考
5. 前瞻性判断记录到 `investment-experience/forward-signals.md`，必须标注待验证假设和验证期限
6. **踏空成本对等规则**: 记录"追涨亏钱"类经验时，必须同时评估"如果等回调而踏空，成本是多少"

### Step 8: 用户数据更新

详细协议：[references/user-context-protocol.md](references/user-context-protocol.md)。

- 用户确认买卖 → 更新 `user-data/user-portfolio.md` + `user-data/trade-history.md`
- 每次分析后 → 更新 `user-data/user-profile.md` 活跃日期/分析次数
- 用户未确认操作 → 不更新持仓，在报告末尾提醒确认

### Step 9: 复盘文档

生成复盘文档到 `docs/review-YYYYMMDD-HHmm.md`，模板详见 [review-loop.md](review-loop.md)。内容包含：分析概要、核心判断依据、前瞻性判断与待验证假设、风险预警清单、经验沉淀引用。

## 常见陷阱（严禁触犯）

1. 跳步执行 — 未完成Phase 1-6就输出报告
2. 搜索不足 — Phase 1少于12次搜索
3. 跳过A股特色数据 — 未搜索连板梯队/龙虎榜
4. 跳过红旗检查 — 未执行14项红旗检查
5. 追高一日游题材 — 评分<6分仍推荐
6. 忽视大盘环境 — 大盘下行时仍重仓
7. 利好出尽追入 — 消息3天+且股价已大涨
8. 忽视量价配合 — 价涨无量=派发陷阱
9. 推荐5板以上空间板 — 风险极大
10. 数据不足仍臆测 — 必须标注"数据不足"
11. 用滞后指标做前瞻决策 — 必须区分领先/确认/滞后指标
12. 忽视渗透率阶段 — 不同阶段策略完全不同
13. 前瞻判断无验证计划 — 必须标注待验证假设和验证期限
14. 主动止盈依赖预判 — 必须用被动信号止盈，不预测顶部
15. 回撤超15%仍不止损 — 必须执行回撤警戒线强制减仓
16. 满仓梭哈 — 必须保持≥10%现金，市场越亢奋仓位越轻
17. 单一周期集中 — 持仓必须跨2个以上周期类型
18. **牛市用防御策略** — 修复上行/景气主升阶段必须进攻性配置，"等回调"不能是默认建议
19. **忽视踏空成本** — 只记录"追涨亏钱"不记录"踏空成本"，经验系统必须双向记录
20. **数据未验证就决策** — WebSearch数据必须通过Step 0.1校验，异常数据禁止用于决策
21. **持仓风格与市场周期错配** — 牛市全仓高股息防御=系统性踏空，必须根据周期调整持仓结构

## 约束条件

- 禁止使用模拟/mock数据，所有数据必须来自实时搜索
- 禁止对亏损股推荐加仓(不向下摊平)
- 禁止推荐ST股、退市风险股
- 禁止给出"一定涨"等绝对性判断
- 所有评级必须附带止损位
- 所有BUY评级必须附带止盈策略（参考 [profit-protection.md](profit-protection.md)）
- 若数据不足，必须标注"数据不足"而非臆测
- 禁止参与纯概念炒作(题材收入占比<1%)
- 禁止推荐5板以上连板股
- 禁止在空头环境(Layer 5≤0分)下推荐任何A股战法
- 禁止推荐庄股/妖股
- A股战法必须与5+1层框架结合使用
- 前瞻性判断必须标注置信度和验证期限
- 禁止用滞后指标(产品价格/利润/融资余额)做前瞻决策
- 账户回撤>15%时必须强制减仓至30%以下（参考 [risk-control.md](risk-control.md)）
- 单板块仓位>30%时必须提示超标风险
- **修复上行/景气主升阶段，BUY评级必须给出趋势确认买入方案，不能只说"等回调"**
- **经验沉淀必须双向记录：记录"追涨亏钱"时也必须评估"踏空成本"**
- **持仓中高股息防御股占比>60%且市场处于修复上行/景气主升时，必须提示"持仓风格与市场周期错配"风险**
- **WebSearch数据必须通过Step 0.1数据验证，未通过校验的数据禁止用于买入/卖出决策**
